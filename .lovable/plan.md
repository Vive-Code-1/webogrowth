

# ক্লায়েন্ট পোর্টালে কমেন্ট/ফিডব্যাক সেকশন

## পরিবর্তন

### 1. নতুন কম্পোনেন্ট — `src/components/ClientTaskComments.tsx`
টাস্কে ক্লিক করলে একটি expandable কমেন্ট সেকশন দেখাবে:
- বিদ্যমান `useComments` ও `useAddComment` হুক ব্যবহার করবে (কোনো নতুন DB টেবিল লাগবে না)
- কমেন্ট লিস্ট: ইউজারের নাম, অ্যাভাটার, সময়, মেসেজ
- কমেন্ট ইনপুট ফিল্ড + সেন্ড বাটন
- RLS ইতোমধ্যে আছে — ক্লায়েন্ট visible tasks এর কমেন্ট পড়তে ও লিখতে পারে

### 2. `src/pages/ClientPortal.tsx` আপডেট
- প্রতিটি টাস্ক row কে ক্লিকযোগ্য করবো
- ক্লিক করলে সেই টাস্কের কমেন্ট সেকশন expand/collapse হবে (Collapsible ব্যবহার করে)
- প্রিমিয়াম ডিজাইন — চ্যাট-স্টাইল বাবল লেআউট

| ফাইল | পরিবর্তন |
|---|---|
| `src/components/ClientTaskComments.tsx` | নতুন — কমেন্ট UI কম্পোনেন্ট |
| `src/pages/ClientPortal.tsx` | টাস্কে ক্লিক → কমেন্ট সেকশন টগল |

কোনো DB মাইগ্রেশন লাগবে না — comments টেবিল ও RLS আগে থেকেই আছে।
